= MetroCluster IP に対するONTAP Mediator サポートの新機能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Mediator サポートの新しいMetroCluster IP 機能と拡張機能について説明します。

ONTAP Mediatorの各リリースの機能と機能拡張の詳細については、link:https://docs.netapp.com/us-en/ontap-mediator/release-notes/whats-new-in-ontap-mediator.html["ONTAPメディエーターの新機能"^]を参照してください。

[cols="4,1"]
|===
| ONTAPメディエーター機能 | 最初から利用可能です 


 a| 
ONTAP Mediator 1.12.1 以降、HTTPS で設定された単一の ONTAP Mediator インスタンスは、以下の構成を同時に監視できます：

* 最大10個の4ノードまたは5個の8ノードMetroCluster IP構成（少なくとも8つのCPUコアと少なくとも16GBのRAMを搭載したホストにインストールした場合）。
* 1つの4ノードMetroCluster IP構成と1つのSnapMirrorアクティブシンクピア関係（2コアCPUを搭載したホストOSにインストールした場合）。


link:../install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["複数の MetroCluster IP 構成に対する ONTAP Mediator サポートの詳細については、こちらをご覧ください"]。
 a| 
ONTAP 9.19.1



 a| 
ONTAP Mediator 1.12は、MetroCluster IP構成で通信にHTTPSを使用するONTAP Mediatorの設定をサポートしています。HTTPS は、SSL/TLS を使用してセッション全体を暗号化することで、セキュリティを強化します。HTTPSプロトコルのみを使用するONTAP Mediatorをインストールすることを選択できます。このインストール方法を使用した場合、SCST パッケージはインストールされません。HTTPSプロトコルのみを使用するONTAP Mediatorのインストールの詳細については、link:https://docs.netapp.com/us-en/ontap-mediator/install/prepare-install.html#https-iscsi-installation["ONTAP MediatorのHTTPSおよびiSCSIインストールオプション"^]を参照してください。

link:../install-ip/concept_mediator_requirements.html#select-a-communication-protocol-for-ontap-mediator["ONTAP Mediator の iSCSI および HTTPS プロトコルの詳細"]。
 a| 
ONTAP 9.19.1



 a| 
MetroCluster IP 構成では、 ONTAP Mediator 1.11 以降で IPv6 がサポートされます。

link:../install-ip/task_configuring_the_ontap_mediator_service_from_a_metrocluster_ip_configuration.html["MetroCluster IP構成用のONTAPメディエーターを設定する"]
 a| 
ONTAP 9.18.1



 a| 
ONTAP Mediator 1.11 では、単一のONTAP Mediator インスタンスを使用して最大 10 個のMetroCluster IP 構成を管理するためのサポートが追加されました。

link:../install-ip/concept_mediator_requirements.html["MetroCluster IP構成にONTAPメディエーターをインストールする準備"]
 a| 
ONTAP 9.18.1



 a| 
環境がシャットダウンした場合は、Mediator-Assisted Automatic Unplanned Switchover（MAUSO；メディエーターアシスト自動計画外スイッチオーバー）がサポートされます。

環境のシャットダウンにより一方のサイトが正常にシャットダウンすると、MAUSOがトリガーされます。

https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept-ontap-mediator-supports-automatic-unplanned-switchover.html["ONTAPメディエーターが計画外の自動スイッチオーバーをサポートする仕組み"]
 a| 
ONTAP 9.13.1



 a| 
MetroCluster IP構成におけるONTAP Mediatorの初期サポート
