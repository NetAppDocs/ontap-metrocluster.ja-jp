= RCFファイルを使用してCisco MetroCluster FCスイッチを設定する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cisco FC スイッチを設定するには、スイッチ設定を工場出荷時のデフォルトにリセットし、スイッチソフトウェアをインストールし、特定の構成のスイッチ設定がすべて定義されたリファレンス構成ファイル（ RCF ）をダウンロードして適用する必要があります。
