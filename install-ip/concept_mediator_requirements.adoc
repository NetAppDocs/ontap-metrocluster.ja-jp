= ONTAP Mediator構成要件（MetroCluster IP構成向け）
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
MetroCluster IP構成でONTAPメディエーターを設定するには、環境が特定の要件を満たしている必要があります。

1つのディザスタリカバリグループ（DRグループ）に次の要件が適用されます。の詳細を確認してください link:concept_parts_of_an_ip_mcc_configuration_mcc_ip.html#disaster-recovery-dr-groups["DR グループ"]。

* Linux バージョンを更新する予定がある場合は、最新バージョンの ONTAP Mediator をインストールする前に更新してください。
* ONTAP Mediator と MetroCluster Tiebreaker ソフトウェアの両方を同じ MetroCluster 構成で使用しないでください。
* ONTAP Mediator は、MetroCluster サイトとは別の場所にある Linux ホストにインストールする必要があります。
+
ONTAP メディエーターと各サイトの間の接続には、2つの異なる障害ドメインが必要です。

* ONTAP 9.7 以降では、自動計画外スイッチオーバーがサポートされます。
* ONTAP 9.19.1およびONTAP Mediator 1.12以降では、iSCSIではなくHTTPSを使用して通信を行うONTAP Mediatorを設定できます。詳細については、<<ONTAP Mediatorの通信プロトコルを選択してください>>を参照してください。
* ONTAP 9.18.1 以降では、 MetroCluster IP 構成のONTAP Mediator 1.11 以降で IPv6 がサポートされます。




[[network-requirements-for-using-ontap-mediator-in-a-metrocluster-configuration]]
== MetroCluster構成でONTAP Mediatorを使用するためのネットワーク要件

MetroCluster 構成に ONTAP Mediator をインストールするには、構成がいくつかのネットワーク要件を満たしていることを確認する必要があります。

* レイテンシ
+
最大レイテンシは75ms（RTT）未満

+
ジッターは5ミリ秒以下である必要があります。

* MTU
+
MTU サイズは 1400 以上にする必要があります。

* パケット損失
+
Internet Control Message Protocol（ICMP）とTCPトラフィックの両方で、パケット損失は0.01%未満でなければなりません。

* 帯域幅
+
ONTAP Mediator と 1 つの DR グループ間のリンクには、少なくとも 20 Mbps の帯域幅が必要です。

* 独立した接続性
+
各サイトとONTAP メディエーターは個別に接続する必要があります。一方のサイトで障害が発生しても、影響を受けない他の2つのサイト間のIP接続は中断しないでください。





[[host-requirements-for-ontap-mediator-in-a-metrocluster-configuration]]
== MetroCluster構成におけるONTAP Mediatorのホスト要件

構成が複数のホスト要件を満たしていることを確認する必要があります。

* ONTAP メディエーターは、2つのONTAP クラスタから物理的に分離された外部サイトにインストールする必要があります。
* ONTAP メディエーターでは、ホストオペレーティングシステムの最小要件であるCPUおよびメモリ（RAM）は必要ありません。
* ホストオペレーティングシステムの最小要件に加えて、使用可能なディスクスペースが少なくとも30GB必要です。
+
** 各DRグループには、最大200MBのディスクスペースが必要です。






[[select-a-communication-protocol-for-ontap-mediator]]
== ONTAP Mediatorの通信プロトコルを選択してください

デフォルトでは、MetroCluster IPノードはiSCSIセッションを使用してONTAP MediatorメールボックスLUNにアクセスします。ONTAP MediatorはSCSTパッケージを利用してiSCSIを提供します。iSCSIセッションは、難読化された機械生成の事前共有鍵を使用したチャレンジハンドシェイク認証プロトコル（CHAP）によって認証されますが、完全に暗号化されるわけではありません。

ONTAP 9.19.1およびONTAP Mediator 1.12以降では、iSCSIではなくHTTPSを使用して通信を行うONTAP Mediatorインスタンスを設定できます。HTTPSは、SSL/TLSを使用してセッション全体を暗号化する安全な通信プロトコルであり、iSCSIと比較してセキュリティが向上しています。

iSCSI と HTTPS の両方をサポートする ONTAP Mediator 、または HTTPS のみをサポートする ONTAP Mediator をインストールできます。詳細については、link:https://docs.netapp.com/us-en/ontap-mediator/install/prepare-install.html#https-iscsi-installation["ONTAP MediatorのHTTPSおよびiSCSIインストールオプション"^]を参照してください。

ONTAP Mediator は iSCSI または HTTPS のいずれかで設定できますが、両方を同時に使用することはできません。デプロイメントにおいて複数のプロトコルを混在させることはサポートされていません。

CLIを使用してHTTPSを使用するONTAP Mediatorのみを設定できます。System Managerはサポートされていません。

複数の MetroCluster IP 構成の監視サポートは、iSCSI または HTTPS 用に ONTAP Mediator を設定するかどうかによって異なります。詳細については、<<ONTAP Mediator を使用して複数の MetroCluster IP 構成を監視する>> を参照してください。



[[use-ontap-mediator-to-monitor-multiple-metrocluster-ip-configurations]]
[[mediator-multiple-mccip]]
== ONTAP Mediator を使用して複数の MetroCluster IP 構成を監視する

ONTAP Mediator は、複数の MetroCluster IP 構成を同時に監視するために使用できます。サポートは、ONTAP Mediator を iSCSI と HTTPS のどちらで構成するかによって異なります。



[[ontap-mediator-configured-with-https]]
=== ONTAP Mediator は HTTPS で構成されています

ONTAP 9.19.1 および ONTAP Mediator 1.12 以降では、iSCSI の代わりに HTTPS を使用して通信を行う ONTAP Mediator インスタンスを設定できます。このセクションでは、1 つの HTTPS ONTAP Mediator インスタンスを使用して複数の構成を監視するためのサポートについて概説します。


CAUTION: このセクションで説明した制限を超えて複数の HTTPS ONTAP Mediator インスタンスを追加しようとすることはサポートされていません。

.複数のMetroCluster IP構成の監視
HTTPS で構成された ONTAP Mediator は、複数の MetroCluster IP 構成の監視に対して以下のサポートを提供します。サポートは、ONTAP Mediator のバージョン、ホスト OS の仕様、および MetroCluster IP 構成が 4 ノードか 8 ノードかによって異なります。

[cols="1,2,1,1"]
|===
| ONTAP Mediatorのバージョン | ホストOSの要件 | 4ノードMetroCluster IP構成 | 8ノードMetroCluster IP構成 


| 1.12 | 該当なし | 1. | 1. 


.2+| 1.12.1以降 | CPUコア数が8未満で、RAMが8GB以上のホスト | 1. | 1. 


| 少なくとも8コアのCPUと少なくとも16GBのRAMを搭載したホスト | 10. | 5. 
|===
.MetroCluster IP および SnapMirror アクティブ同期構成の監視
ONTAP 9.19.1 および ONTAP Mediator 1.12 以降では、同じ ONTAP Mediator インスタンスを使用して、4 ノードの MetroCluster IP 構成と SnapMirror アクティブ シンクのクラスタ ピア関係を同時に監視できます。構成は次の要件を満たしている必要があります。

* ONTAP Mediator 1.12.1以降が2コアCPUを搭載したホストOSにインストールされていること
* ONTAP MediatorインスタンスはHTTPSプロトコルで構成されています



NOTE: 同じ ONTAP Mediator インスタンスを使用して監視できるのは、4 ノードの MetroCluster IP 構成 1 つと、SnapMirror アクティブ同期ピア関係 1 つのみです。

link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/index.html["ONTAP SnapMirror Active Syncについて学ぶ"^]。



[[ontap-mediator-configured-with-iscsi]]
=== ONTAP MediatorはiSCSIで構成されています

* ONTAP 9.18.1およびONTAP Mediator 1.11以降では、iSCSIで構成された単一のONTAP Mediatorインスタンスで、最大10個のMetroCluster構成を同時に管理できます。
* ONTAP 9.17.1およびONTAP Mediator 1.10以前では、iSCSIで構成されたONTAP Mediatorは、最大5個のMetroCluster構成を同時にサポートできます。




[[guidelines-for-upgrading-ontap-mediator-in-a-metrocluster-configuration]]
== MetroCluster構成でONTAP Mediatorをアップグレードするためのガイドライン

ONTAP Mediator をアップグレードする場合は、Linux バージョンの要件を満たし、アップグレードのガイドラインに従う必要があります。

* ONTAP Mediator は、直前のバージョンから現在のバージョンにアップグレードできます。
* MetroCluster 9.7 以降を実行する ONTAP IP 構成では、すべてのメディエーターのバージョンがサポートされます。


link:https://docs.netapp.com/us-en/ontap-mediator/index.html["ONTAPメディエーターをインストールまたはアップグレードする"^]



[[after-the-upgrade]]
== アップグレード後

メディエーターとオペレーティングシステム問題のアップグレードが完了したら、「 storage iscsi-initiator show 」コマンドを実行して、メディエーター接続が稼働していることを確認する必要があります。
