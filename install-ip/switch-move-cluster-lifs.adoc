= MetroCluster IP構成でスイッチ、RCF、またはファームウェアの変更前にクラスタLIFを移動する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
MetroCluster IPスイッチを交換したり、スイッチのファームウェアや参照構成ファイル（RCF）を変更したりする場合は、クラスタLIFをパートナースイッチに移動して、クラスタの無停止運用を実現する必要があります。

.このタスクについて
* スイッチのファームウェアをアップグレードまたはダウングレードする前、スイッチのRCFを交換する前、またはIPスイッチを交換する前に、この作業を実行する必要があります。
+

NOTE: スイッチを初めて設定する場合は、スイッチの交換作業を行わない限り、この手順はスキップできます。

* このタスクでは、ONTAP コマンドとスイッチコマンドの両方を使用する必要があります。特に指定がない限り、ONTAP コマンドが使用されます。
* この手順で使用する例では、IP_switch_A_1 をアップグレードするため、クラスタ LIF を IP_switch_A_2 に移行する必要があります。
* この手順のコマンド出力例は、Cisco スイッチの詳細を示しています。出力は、スイッチの機種やメーカーによって異なる場合があります。

. クラスタLIFの自動ロールバックを無効にします。クラスタLIFはパートナークラスタスイッチにフェイルオーバーし、対象のスイッチでアップグレード手順を実行する間、その場所に留まります。
+

NOTE: 2番目のファブリックをアップグレードする場合は、この手順をスキップして、<<shut-down-ports,手順 4>>に進んでください。

+
`network interface modify -vserver Cluster -lif * -auto-revert false`

+
.例を表示
[%collapsible]
====
[listing, subs="+quotes"]
----
cluster_A::*> network interface modify -vserver Cluster -lif * -auto-revert false

Warning: Disabling the auto-revert feature of the cluster logical interface may
         effect the availability of your cluster network. Are you sure you want
         to continue? {y|n}: y

Warning: Changes to a cluster LIF can affect the health of the Cluster. Are you
         sure you want to continue? {y|n}: y
4 entries were modified.
----

.完了後
クラスタLIFがパートナースイッチに移行したら、スイッチベンダーの標準設定手順に従って、ターゲットファームウェアまたはRCFバージョンへのアップグレードを完了できます。

* link:../install-ip/task_switch_config_broadcom.html["Broadcom IP スイッチを設定します"]
* link:../install-ip/task_switch_config_cisco.html["Cisco IP スイッチを設定する"]
* link:../install-ip/task_switch_config_nvidia.html["NVIDIA IPスイッチを設定します"]



NOTE: 最初のファブリックでスイッチを設定した後、2番目のファブリックでクラスタLIFを移動する手順を繰り返す必要があります。
